### About Me

- I'm based in **South Africa**
- I’m currently working on **SmartHydro**, a fully automated smart hydroponic farm orchestrating hardware via MQTT and Docker.
- I'm developing a **Telemetry Gathering Engine** using core data structures (trees, linked lists, queues) for high-performance data ingestion.
- My core focus is building **secure, robust backends** while remaining highly capable across frontend, cross-platform, and mobile development.
